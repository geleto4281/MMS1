# Documentation

The root [README](../README.md) is the maintained starting point for local
development and deployment. Supporting guides are grouped by purpose:

- [`setup/`](./setup/) contains Firebase and local setup references.
- [`architecture/PROJECT_STRUCTURE.md`](./architecture/PROJECT_STRUCTURE.md)
  documents the current source layout.
- [`archive/`](./archive/) contains older project notes retained for context;
  prefer the root README when instructions conflict.
